# Yuno Music Player

Кроссплатформенный музыкальный плеер (Android, Windows, iOS) со сквозным поиском, воспроизведением без ограничений, синхронизированными караоке-субтитрами и облачной библиотекой.

---

## Структура проекта

- **`backend/`** — Сервер на Python 3.12 (FastAPI, SQLite, yt-dlp, LRCLIB)
  - Стрим-прокси с поддержкой перемотки (`HTTP Range`) и кэшированием треков
  - Синхронизированные караоке-субтитры (LRC с миллисекундной точностью)
  - Сквозной поиск и рекомендации
  - Авторизация (JWT) и облачное хранилище плейлистов/лайков
- **`app/`** — Мобильный и десктопный клиент на Flutter
  - Фоновое воспроизведение и системная шторка Android (`just_audio` + `audio_service`)
  - Интерактивный экран караоке-субтитров с автоскроллом и перемоткой по тапу на строчку
  - Spotify-стиль: минималистичная темная тема (`#121212`) и фиолетовый акцент логотипа Yuno (`#7C3AED`)
- **`assets/`** — Официальный логотип и иконки Yuno

---

## Запуск проекта

### 1. Запуск бэкенда

```powershell
cd backend
.\.venv\Scripts\activate
python run.py
```
Сервер запустится на `http://0.0.0.0:8000`. Интерактивная документация Swagger доступна по адресу `http://localhost:8000/docs`.

### 2. Запуск Android / Windows клиента

```powershell
cd app
flutter run
```

При запуске на физическом телефоне в одной Wi-Fi сети укажите локальный IP вашего компьютера (например, `http://192.168.1.50:8000`) в настройках сервера на экране входа.
